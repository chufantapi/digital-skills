How to start learning cloud and DevOps engineering as a complete beginner

Cloud and DevOps engineering is about running software on cloud platforms such as AWS, Azure or Google Cloud, and automating how that software is built, tested and released.

Learn Linux and networking

Most servers run Linux, so learn the command line, file permissions and basic networking such as IP addresses, DNS and ports.

Learn to script

Learn basic scripting in Bash or Python to automate repetitive tasks.

Learn the core tools

Study Git for version control, containers with Docker, and the idea of CI/CD, where code is tested and deployed automatically.

Choose one cloud platform

Pick AWS, Azure or Google Cloud, use its free tier and learn its core services for computing, storage and networking. Set cost alerts so you are not charged by accident.

Build something

Deploy a simple web app to the cloud with a pipeline that updates it automatically whenever you change the code.
