How to start learning Agile project management as a complete beginner

Agile project management means running projects in short cycles, often called sprints, with regular feedback instead of one long plan. It is widely used in software and increasingly in other industries.

Learn the core ideas

Understand the Agile values and frameworks such as Scrum and Kanban. Learn the common roles, such as product owner, scrum master and team member, and events such as sprint planning and daily stand-ups.

Learn the tools

Practise with a free board tool such as Trello, or the free plans of tools like Jira, to manage tasks, sprints and backlogs.

Build people skills

Project managers spend most of their time communicating, so practise running a short meeting, writing clear tasks and reporting progress.

Run a real project

Manage a small project in sprints, such as planning an event or building a personal website, and note what you learnt after each sprint. Entry-level certifications exist, so check which ones employers in your area ask for.
