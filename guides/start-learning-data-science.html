How to start learning data science as a complete beginner

Data science uses statistics and programming to find patterns in data and to build models that make predictions. It is a bigger step than data analytics, so give yourself time and build the foundations in order.

Start with data basics

Learn spreadsheets and SQL first. Almost every data science task starts with getting data out of a database and cleaning it, and these two skills make that easy.

Learn some statistics

You do not need advanced maths to begin. Understand averages, spread, probability and how to tell whether a pattern is real or just chance. These ideas matter more than any tool.

Learn Python

Python is the most common language in data science. Start with the basics, then learn a library for working with tables of data, such as pandas, and one for charts.

Move on to machine learning later

Machine learning teaches a computer to make predictions from examples. Learn it only after the steps above, or you will be copying code you do not understand.

Build a portfolio

Choose two or three real datasets, ask a clear question of each, and explain your method and results. Employers look for proof that you can do the work.
